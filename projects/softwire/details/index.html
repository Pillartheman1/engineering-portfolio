Softwire Themes: engineering deep dive

An open-source pack of five matching desktop themes for Omarchy Linux, installed with one command.

Designer & developer (solo) · Sep 2026 – present

StatusParametersShared systemPackagingDesign decisionsTesting

Status

Complete. Five themes released with install and uninstall scripts. Theme configuration is MIT; bundled fonts and wallpapers keep their own licenses.

ThemeIdentityWindow opacity

Shared system

  • Same type, icons and layout across all five
  • Glass: 50% shell surfaces (bar, menus, notifications) plus blurred window opacity
  • Fonts: Andromeda (titles, freeware non-commercial), Y224 (numbers, CC0), licenses included
  • Wallpapers bundled per theme; extras cycle with omarchy theme bg next

Packaging

ScriptBehavior
install.shOne command installs all five; re-running updates and re-applies the active Softwire theme
uninstall.shSwitches to a stock theme first if a Softwire theme is active, then removes all five
omarchy theme installNot used: it clones a single theme, so it can't install a pack

Design decisions

DecisionAlternativesChoice & rationale
InstallerStock single-theme installOwn install.sh: supports a five-theme pack; one more script to maintain
OpacityOne value for all themesTuned per palette (65–80%): readability per theme
Uninstall safetyDelete files onlySwitch theme first so the desktop isn't left on a deleted theme
FontsAny display fontRedistributable fonts only (freeware/CC0) with licenses bundled

Testing

  • Installer and uninstaller checked against a live Omarchy desktop
  • Iterated on the White theme's wallpaper and default
  • Download metrics: not tracked

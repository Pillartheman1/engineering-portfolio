Context Deployment: engineering deep dive

An open-source Omarchy Linux plugin: Super+right-click anything on the desktop to have your AI agent edit it in context.

Sole developer · Sep 2026 – present

Status

Complete. Released v1.2.0 under the MIT license. Plugin ID daniel.desktop-context.

Requirements

RequirementHow it's met
Open from the desktop without breaking window resizingSuper+right-click opens the menu; bind uses click = true so Super+right-drag still resizes
Send visual context to the agentCaptures what's under the click plus a crop around the cursor
Work with any agentSends to omarchy-agent, i.e. the user's default (omarchy default agent <name>)
Edits must be reversibleConfig snapshot before each mutating edit; Undo last edit restores it
Safe to trustOpen source; README warns that plugins run unsandboxed

Architecture

ComponentRole
Main.qmlOverlay menu inside omarchy-shell
scripts/open.shEntry point bound to Super+right-click
scripts/context.pyFinds the monitor, window or bar under the cursor via hyprctl; crops a 512×320 region clamped to the monitor
scripts/session.pyTracks the last session for Continue and Undo
scripts/run-action.sh, run-edit.sh, launch-agent.shRun the chosen action and launch the agent
manifest.jsonOmarchy plugin manifest

Menu actions

ActionWhat it does
EditPrompt, then send click context + crop to the agent
What is this?Same context; the agent explains and does not edit
DictateVoice input into the prompt (hidden if the dictation tool isn't installed)
ContinueFollow-up with a new click after the first Inspect or Edit
Undo last editRestore the config snapshot from before the last mutating edit

Design decisions

DecisionAlternativesChoice & rationale
Context sizeFull screenshot512×320 crop around the cursor: less noise; context outside the crop is lost
UndoRely on git/manual backupsAutomatic snapshot: extra writes, one-click recovery
AgentHard-code one agentUser's default agent: works with any; behavior depends on the agent
KeybindPlain Super+right-clickClick-only bind so the drag-resize gesture survives

Install

omarchy plugin add https://github.com/Pillartheman1/omarchy-context-deployment.git --enable, then add the keybind from the README and run hyprctl reload.
